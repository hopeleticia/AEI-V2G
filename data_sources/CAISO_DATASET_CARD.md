# CAISO Real Grid Load Profile Dataset Card

## Dataset

`data/grid_profiles/caiso_2024-05-01_2024-05-07.csv`

## Source

California ISO Today's Outlook demand chart data.

- Source page: `https://www.caiso.com/todays-outlook/`
- Historical CSV pattern: `https://www.caiso.com/outlook/history/YYYYMMDD/demand.csv`
- Download command:

```powershell
python -m data_sources.download_caiso_load --start 2024-05-01 --end 2024-05-07 --output data/grid_profiles/caiso_2024-05-01_2024-05-07.csv
```

## Columns

| Column | Meaning |
|------|---------|
| `timestamp` | Local timestamp reconstructed from CAISO chart date and time |
| `date` | Source date |
| `time` | Source chart time |
| `day_ahead_forecast_mw` | CAISO day-ahead demand forecast |
| `hour_ahead_forecast_mw` | CAISO hour-ahead demand forecast |
| `current_demand_mw` | CAISO current demand value |
| `demand_response_mw` | Demand response value when present |
| `source` | `CAISO` |

## Use in AEI-V2G

The default corridor config now points to this file:

```yaml
grid:
  load_profile_csv: data/grid_profiles/caiso_2024-05-01_2024-05-07.csv
```

`sim.load_profile.LoadProfile` imports `current_demand_mw` and `sim.grid_model.GridModel` uses the normalized real load profile as part of the grid-stress signal. EV traffic and station behavior are still generated by the AEI-V2G digital twin, but the grid-load shape is grounded in a public CAISO operational demand profile.

## Limitations

CAISO Today's Outlook data is public operational chart data. CAISO notes that demand and net-demand trend data are informational and exclude dispatchable pump loads and battery charging load. Use this dataset to defend realistic grid-load shape, not billing-grade settlement accuracy.
